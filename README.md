# @markormesher/biome-config

Standard [Biome](https://biomejs.dev) config for my TypeScript/React/SCSS projects.

## Installation and Usage

Install from GitHub:

```shell
pnpm add --save-dev @markormesher/biome-config@https://github.com/markormesher/biome-config#semver:^0.1.0
# or
yarn add --dev @markormesher/biome-config@https://github.com/markormesher/biome-config#semver:^0.1.0
```

Add it to `biome.json`:

```json
{
  "extends": ["@markormesher/biome-config/biome-config"]
}
```
